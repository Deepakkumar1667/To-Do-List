# TaskFlow — Professional To-Do List

TaskFlow is a simple and professional **To-Do List web application** built using **HTML, CSS, and Vanilla JavaScript**.

It helps users organize their daily tasks, track completed work, and manage their tasks through a clean and responsive interface.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Filter tasks:

  * All
  * Active
  * Completed
* View task statistics

  * Total Tasks
  * Active Tasks
  * Completed Tasks
* Clear all completed tasks
* Save tasks using **Local Storage**
* Tasks remain available after refreshing the browser
* Press **Enter** to quickly add a task
* Responsive design for desktop, tablet, and mobile
* Clean and professional user interface

## Technologies Used

* **HTML5** — Structure of the application
* **CSS3** — Styling and responsive design
* **JavaScript** — Application logic and interactivity
* **Local Storage** — Saving tasks in the browser

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No server or installation is required.

## How It Works

### Add a Task

Enter a task in the input field and click **Add Task** or press **Enter**.

### Complete a Task

Click the checkbox next to a task to mark it as completed.

### Delete a Task

Click the **Delete** button to remove a task.

### Filter Tasks

Use the filter buttons to display:

* **All** — Shows all tasks.
* **Active** — Shows unfinished tasks.
* **Completed** — Shows finished tasks.

### Local Storage

TaskFlow uses the browser's `localStorage` to save tasks. This means your tasks remain available even after refreshing or reopening the browser.
